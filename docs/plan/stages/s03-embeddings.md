# s03. Эмбеддинги Qwen

Статус: PASS для `qwen/qwen3-embedding-8b`, 4096 измерений. Повторно не извлекать. Ключ кэша не менять.

## Назначение

Заморозить одно представление текста. Все головы корпусного плеча сидят на этих векторах. Это не обучение детектора «с нуля» и не сравнение эмбеддеров.

## Входы

Тексты train, val и test из `result/01_data`. Бэкенд, который этап принимает для этого корпуса, — RouterAI. Имя модели — `qwen/qwen3-embedding-8b`. Другой бэкенд код этапа отвергает. Ревью 4 ноября обсуждало EmbeddingGemma; эмбеддер не переключался и сейчас не переключается.

## Выходы

`result/03_embeddings/train.npy`, `val.npy`, `test.npy` и `cache_hash.json`. Размерность 4096. Число строк совпадает с s01: 324 991 / 69 641 / 69 642.

Ключ кэша: бэкенд, модель, размер батча, число текстов, усечённый SHA-256 первого текста и усечённый SHA-256 последнего. Хеша каждой строки и хеша исходника в ключе нет. Комментарий в `src/cache.py` фиксирует формулу, потому что s03 пишет её в метаданные частичного прогона. Формулу не трогать.

## Критерий pass/fail

Принятый pass: три матрицы существуют, размерности и числа строк сходятся с разбиением, модель — названная выше. Повторный прогон при том же ключе обязан брать кэш, а не ходить в API.

Fail, которого сейчас нет оснований объявлять: перепутанный порядок строк относительно меток. Ревью 6 ноября по доступному коду такое несоответствие не подтверждает. Высокая точность MLP сама по себе его не доказывает и не опровергает.

## Ещё открыто

Ключ не заметит перестановку внутренних строк, если первая, последняя и длина серии те же. Исправление — новый ключ для будущих корпусов, отдельным изменением, без перезаписи принятых `*.npy` и без пересчёта s03. Пока ключ старый, принятые файлы не пересобирать «для надёжности»: повторный запрос к API при смене ключа создаст другую матрицу и сломает s04 и живой s05.

Выборочная повторная выдача нескольких эмбеддингов, которую ревью называет проверкой кэша, допустима только после конца s05 и только в новый каталог, без замены `train.npy`.

## Что нельзя утверждать

Что PASS s03 доказывает построчное соответствие при любом будущем изменении порядка. Что представление выделяет «общие признаки AI-текста», а не источник, шаблон или регистр. Что смена эмбеддера сохранила бы ту же кривую ширин.
