# s01. Корпус и разбиение

Статус: размеры и схема разбиения приняты. Близкие тексты между частями не проверены. Этап не перезапускать.

## Назначение

Зафиксировать, на каком корпусе и на каком разбиении сидят все последующие чистые прогоны. Новое разбиение сменило бы порядок текстов и разошлось бы с уже принятым кэшем эмбеддингов.

## Входы

Локальный корпус, который пайплайн читает как `DATA_PATH` (по умолчанию `data/AI_Human.csv`). Происхождение, принятое в работе: зеркало Hugging Face `andythetechnerd03/AI-human-text`, а не побайтовая копия CSV Kaggle. Исходные части зеркала объединяются, затем строится новое случайное разбиение. Манифест происхождения — `data/source_manifest.json` на принятой ветке. Этот план файл не перечитывал и числа из него не подменяет.

## Выходы

Каталог `result/01_data`: `train.parquet`, `val.parquet`, `test.parquet`, `cache_hash.json`. Колонки, которые дальше читают этапы: `text`, `generated`.

Принятые размеры после очистки: 464 274 строки. Seed 42, доли 70/15/15.

| Часть | Строк | Состав |
| --- | ---: | --- |
| train | 324 991 | AI 125 754 / human 199 237 |
| val | 69 641 | |
| test | 69 642 | |

Очистка в коде: пустые тексты выбрасываются, точные дубликаты по `text` удаляются, разбиение стратифицировано по `generated`. Режим `full` эти размеры и использует. Режим `fast` в коде — не «первые 100 строк» из `objective.md`, а подвыборка до 1024 строк на класс. Живой s05 запущен с `--mode full`.

## Критерий pass/fail

Pass уже принятого этапа: три parquet и хеш кэша соответствуют полному режиму и seed 42, а суммы строк сходятся с таблицей выше. Fail для научной независимости test этим не закрывается: точное совпадение строк не ловит перефразы и общие шаблоны. Такой fail не переводит этап в «переделать разбиение».
