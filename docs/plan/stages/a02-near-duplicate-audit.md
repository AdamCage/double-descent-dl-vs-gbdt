# a02. Близкие тексты между разбиениями

Статус: не запускать, пока жив s05. Разбиение s01 не пересобирать. Принятые эмбеддинги не заменять.

## Назначение

Ограничить открытое замечание протокола 4 ноября: точные дубликаты удалены, почти одинаковые эссе между train, val и test не проверялись. `scientific_validity` после отчёта остаётся `not_assessed`. Аудит не «очищает» корпус и не даёт права переразбить данные под уже посчитанный s03.

## Входы

Тексты и метки train, val, test из `result/01_data`. Для косинуса — `result/03_embeddings/{train,val,test}.npy`, только чтение.

Два заранее заданных измерения.

Мини-хэш по тексту, основное:

- шинглы: слова окнами по 3 и символы окнами по 5, нижний регистр, как две отдельные оценки;
- 64 перестановки, seed 42;
- для каждой строки val и каждой строки test — максимальный Jaccard к train.

Косинус эмбеддингов, дополнительное и неполное:

- ровно 2 000 строк val и 2 000 строк test, стратифицированных по `generated`, seed 42;
- точный максимум косинуса к train, блоками, без приближённого индекса;
- полная пара val×train и test×train не назначается: при 4096 измерениях это отдельная по стоимости работа, и этот план её не ставит.

Пороги отчёта, не пороги «годности корпуса»: Jaccard 0.80; косинус 0.95 и 0.99. Кроме долей выше порога записать квантили 0.50, 0.90 и 0.99 распределения максимума. Для масштаба — 2 000 случайных пар внутри train, seed 42, те же меры.

## Выходы

`result/a02_near_duplicates/`: описание процедуры, написанное до счёта, доли и квантили, число строк с соседом выше каждого порога, отдельно val и test, отдельно каждый тип шингла. Примеры пар — короткие цитаты начал, не выгрузка корпуса. В `result/01_data` и `result/03_embeddings` не писать.

## Критерий pass/fail

Pass: отчёт покрывает оба шингла и выборочный косинус, пороги те, что выше, процедура не менялась после просмотра доли.

Научного pass «утечки нет» у этапа нет. Доля выше порога ограничивает доверие к val accuracy 0.999. Нулевая доля на выборочном косинусе не закрывает пары вне 2 000 строк и не закрывает общий шаблон с низким Jaccard.

Fail: переразбиение; удаление найденных пар из принятых parquet; подмена порога после того, как доля оказалась большой или маленькой; полный пересчёт эмбеддингов.
