# Реестр первичной литературы

[sources.json](sources.json) — машиночитаемый начальный реестр, проверенный 2026-11-07 по страницам первичных публикаций/arXiv. Статус `metadata_and_abstract_verified` означает проверку названия, авторов, версии и аннотации по указанной странице. Это не полнотекстовая экспертиза, воспроизведение результатов или одобрение переноса теорем на наш код. Локальные PDF пока не архивированы; отсутствие snapshot/hash явно записано.

Начальный реестр не претендует на полноту обзора. Результаты Curth/Comesaña и Kanoh не сводят к общему «у бустинга бывает/не бывает двойного спуска»: сначала сравнивают определения осей, learning setup и условия. Новизна проекта не может состоять лишь в ещё одном пике CatBoost.

Перед использованием источника в подтверждающем протоколе Cursor сохраняет разрешённую копию/стабильную версию, retrieval date, SHA-256, библиографию, locators соответствующих утверждений и заметку о допущениях. Если скачать нельзя, записывает причину и permalink; не выдумывает snapshot. Содержательное review выполняет отдельный Cursor субагент; evidence packet для Codex/человека нужен при критических вопросах и верхнеуровневой критике. В реестре различаются `verified`, `unverified`, `superseded` и `retracted` при появлении проверяемых оснований; обновления сохраняют историю.

`claim_map` связывает литературу с предлагаемыми вопросами/дизайном. Это ссылки на внешние результаты и мотивы исследования, не эмпирические claims нашего проекта. Для собственных claims нужны локальные неизменяемые артефакты и review.

Файлы в `articles/` сохраняются как унаследованные обзорные заметки. Их утверждения и ссылки не приобретают валидность автоматически из-за наличия в репозитории. Полнотекстовый разбор, поиск новых работ, проверка датасетов и оценка новизны входят в R1 до новых экспериментов.
