# Проверка литературы для ревизии v2

Проверено 7 ноября 2026. Автор: `/root/literature`, отдельный литературный
субагент. Это целевой поиск первичных источников, а не систематический обзор
и не доказательство приоритета. Документ не принимает научные claims проекта.

## Что уже известно

**L07 подтверждён, включая дату.** Ryuichi Kanoh,
[Double Descent in Gradient Boosting Decision Trees via Split-Candidate Scaling](https://arxiv.org/abs/2608.03111v1),
arXiv:2608.03111v1, 4 августа 2026.
[HTML фиксированной версии](https://arxiv.org/html/2608.03111v1).
Проверены §§ Introduction, From Split Candidates to Path Features and Tree
Kernels, Experiments, Setup, Results. Работа уже рассматривает вложенные
префиксы split candidates, отдельный контроль native border_count, спектр
reference tree kernel, зависимость от глубины, размера train и label noise,
возникновение пика при длительном обучении и сравнение CatBoost/XGBoost/
LightGBM. В ней есть дополнительная проверка на 18 табличных наборах.
Следовательно, само обнаружение двойного спуска в CatBoost, сдвиг пика с n
или глубиной и медленное проявление пика во времени уже не являются новыми
вкладами. Reference kernel в статье явно не объявлен точным описанием
адаптивной стандартной GBDT. Перепроверка этих результатов полезна как
репликация, но не должна называться новым механизмом.

**L05 подтверждён.** Alicia Curth, Alan Jeffares, Mihaela van der Schaar,
[A U-turn on Double Descent: Rethinking Parameter Counting in Statistical Learning](https://papers.nips.cc/paper_files/paper/2023/hash/aec5e2847c5ae90f939ab786774856cc-Abstract-Conference.html),
NeurIPS 2023. Проверены metadata и abstract официального proceedings.
Статья исследует смешивание разных осей роста параметров и smoother-based
effective number of parameters. Её вывод о разобранных конструкциях нельзя
превращать в запрет любого двойного спуска у GBDT: это вступило бы в конфликт
с более узкой постановкой L07 и потребовало бы отдельного доказательства.

**L08 подтверждён.** Aleksei Ustimenko, Artem Beliakov, Liudmila Prokhorenkova,
[Gradient Boosting Performs Gaussian Process Inference](https://arxiv.org/abs/2206.05608v3),
версия v3 от 13 марта 2023. Проверены metadata и abstract. Связь симметричных
деревьев с kernel ridge/GP уже существует. Из одного abstract нельзя переносить
эквивалентность на произвольную CatBoost Logloss-конфигурацию.

## Детекция: приоритет уже занят общей статистикой

Joonpyo Kim, Hee-Seok Oh, Haeran Cho,
[Moving sum procedure for change point detection under piecewise linearity](https://arxiv.org/abs/2208.04900v3),
v3 от 24 августа 2023. Проверены metadata и abstract. MOSUM обнаруживает
скачки и изменения наклона; заявлены асимптотический FWER, состоятельность
и работа при определённых видах зависимости и тяжёлых хвостов. Нельзя
объявлять первый общий метод поиска ускорения по локальным наклонам или
считать такой скан автоматически новым статистическим методом.

Zhibing He, Dan Cheng, Yunpeng Zhao,
[Multiple Testing of Local Extrema for Detection of Structural Breaks in Piecewise Linear Models](https://arxiv.org/abs/2308.04368v5),
v5 от 13 января 2026. Проверены metadata и abstract. Сглаживание,
дифференцирование, локальные экстремумы и множественное тестирование для
разрывов линейных траекторий с Gaussian noise также уже исследованы.
Это важный контроль при формулировании вклада нового детектора.

[Официальная документация CatBoost: Parameter tuning](https://catboost.ai/docs/en/concepts/parameter-tuning),
разделы Learning rate и Random strength, проверена 7 ноября 2026.
Learning rate меняет шаг и требуемое время обучения. В описании random_strength
указан шум scoring разбиений с уменьшающейся по ходу обучения дисперсией.
Это мотивирует потенциальный контраст, но само по себе не доказывает причину
какого-либо позднего ускорения.

## Допустимая формулировка собственного вклада

Перспективна конкретная проверяемая методология интерпретации траекторий
бустинга: отдельно определить ускорение train loss, немонотонность held-out
риска по одной оси и положение измеренного интерполяционного перехода;
проверить чувствительность и ложные срабатывания на заранее заданных классах
траекторий; затем проверить выводы на неадаптируемом наборе обучений.
Общий детектор change points при этом является baseline, а вкладом могут
стать выявленные ограничения интерпретации и валидированный прикладной
протокол. Это гипотеза о возможной ценности, не установленный приоритет.

Отдельный аналитический контроль можно получить собственной алгеброй:
для неизменного симметричного PSD оператора squared-loss gradient descent
при устойчивом постоянном шаге train loss есть сумма неотрицательных
геометрических последовательностей. Поэтому абсолютные последовательные
уменьшения loss не возрастают. Устойчивое ускорение несовместимо с этим
ограниченным описанием. Это элементарное следствие спектрального разложения,
не новый общий theorem и не утверждение о Logloss или адаптивных деревьях.

Заданное изменение learning rate может служить положительным контролем
детектора, но не воспроизведением естественного позднего ускорения. Наличие
такого контроля не разрешает объяснять ещё не наблюдённый естественный эффект.
Отрицательный результат на фиксированном меню должен сохраняться.

## Границы проверки

Целевые запросы о CatBoost late-stage loss acceleration, second loss drop,
плато train loss и detector calibration не выявили отдельной первичной работы,
устанавливающей именно обсуждаемый феномен. Это ограниченный результат поиска,
не доказательство отсутствия литературы. Проверка исследовательского
приоритета остаётся открытой.
