# Что идентифицирует ускорение loss

Автор вывода: Codex `/root`, 7 ноября 2026. Это самостоятельная элементарная
алгебра, не заявка на новый theorem. Рецензируется отдельно от реализации.
Ссылки на известные методы и пределы проверки приоритета:
`docs/literature/2026-11-07-v2-audit.md`.

## Конструктивная неидентифицируемость по одной кривой

Пусть наблюдалась любая конечная последовательность
L_0 >= L_1 >= ... >= L_T > 0. Возьмём неизменную одномерную функцию
f(x)=x²/2, x_0=sqrt(2 L_0), и шаги

η_t = 1 - sqrt(L_(t+1)/L_t),  t=0,...,T-1.

Каждый η_t принадлежит [0,1). Обычный gradient descent даёт
x_(t+1)=x_t-η_t x_t=(1-η_t)x_t=sqrt(2 L_(t+1)). Следовательно,
f(x_t)=L_t точно для всех t. Плато воспроизводится η_t=0, а любое позднее
ускорение монотонного loss — изменением шагов на одной неизменной квадратике.
По одной такой кривой нельзя установить смену представления, разбиений,
kernel или способность к обобщению. Известное постоянство learning rate
убирает именно эту альтернативу, но не все альтернативные объяснения.

В этой конструкции точные часы
τ_t=-2 sum_(s<t) log(1-η_s)
дают L_t=L_0 exp(-τ_t). Они определены после выбора конкретной квадратичной
модели. Часы CatBoost sum η_s — лишь заранее заданная диагностическая
нормировка; они не эквивалентны τ без предпосылок о кривизне и обновлениях.
Расположение максимума score в разных часах само по себе не выявляет механизм.

## Ограниченный контроль со стационарным PSD оператором

Пусть r_(t+1)=(I-ηK)r_t, K симметричен PSD, η постоянен,
0 <= η λ_i <= 2 для всех собственных значений. Для squared train loss
L_t=||r_t||²/(2n) спектральное разложение даёт

L_t = sum_i a_i² q_i^t/(2n),  q_i=(1-η λ_i)² ∈ [0,1].

Уменьшение D_t=L_t-L_(t+1)=sum_i a_i²(1-q_i)q_i^t/(2n)
неотрицательно и не возрастает: D_(t+1)<=D_t.
Устойчивое увеличение абсолютных уменьшений несовместимо с ЭТОЙ моделью.
Но нарушение не различает изменение K, шагов, loss, регуляризации,
стохастику или ошибку измерения. Вывод не относится автоматически к LogLoss,
CatBoost, adaptive tree selection или произвольному kernel approximation.

## Три самостоятельных вопроса аудита

1. **Оптимизация:** увеличилась ли скорость уменьшения train loss на явно
   указанной шкале времени? Детектор требует оценки ошибок и разрешения сетки.
2. **Обобщение:** вырос ли затем снизился held-out риск по одной фиксированной
   оси? Минимум train loss и ускорение сами по себе на это не отвечают.
3. **Интерполяционная интерпретация и механизм:** измерен ли train error/residual,
   локализован ли переход и согласуются ли вмешательства с причинным прогнозом?
   Нулевая classification error не равна нулевой LogLoss. Измеренная скобка
   нужна для claims о связи с интерполяцией, а не для любого описания формы риска.

R10 отвечает на измерительный вопрос при известных synthetic null laws.
R11 вмешивается в расписание шагов и измеряет train/validation/test отдельно.
Положительный контроль с заданным скачком learning rate не считается
воспроизведением естественного ускорения. Синтетические rank thresholds при
применении к CatBoost описательны: обменность с calibration не установлена.
